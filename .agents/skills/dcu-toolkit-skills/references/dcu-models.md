## PCIe Device ID → 型号映射（实测优先 + dcuprofiletools 源码）

`lspci -nn` 中 DCU 设备的识别方式：`[厂商ID:设备ID]`，厂商 `1d94` = 海光DCU（Chengdu Haiguang / C-3000）。
匹配关键字：`Co-processor [0b40]` 类设备即 DCU 卡。

| 厂商:设备ID | 对应产品型号 | 来源 | 工具识别 |
|---|---|---|---|
| **1d94:6370** | **BW100**（芯片ID 6370） | 真机实测 8卡 | ❌ 工具报0张（未含此ID） |
| **1d94:6320** | **BW150 / BW1000**（共用6320，芯片/板卡级ID非产品名） | BW150 真机实测；BW1000 用户确认 | ✅ 正常 |
| **1d94:6430** | **BW1100**（HYGON DCU-3G，芯片ID 6430） | 用户实测 `1d94:6430` | ✅ 正常 |
| 54b7 | Z100 | dcuprofiletools 源码 | ✅ |
| 55b7 | Z100L | dcuprofiletools 源码 | ✅ |
| 62b7 | K100 | dcuprofiletools 源码 | ✅ |
| 6210 | K100-AI | dcuprofiletools 源码 | ✅ |
| 6211 | K100-AI-ECO | dcuprofiletools 源码 | ✅ |

> ⚠️ **重要区分：产品型号 vs 芯片ID**
> - 用户所给 BW100/BW150/BW1000/BW1100/BW10/K100-AI/K100/Z100L/Z100 均为**产品型号**。
> - `1d94:6370`/`6320`/`6430` 是 `lspci` 里的**芯片/板卡级设备ID**，不是产品名（不存在 "BW3000" 产品）。
> - 实测/确认：BW100→6370，BW150→6320，BW1000→6320（与BW150共用），BW1100→6430。
> - 工具的 `dcu_id_map` 未含 `6370`/`6430`，对 BW100/BW1100 会报"0张DCU"——dcu-topology 须自行解析 `lspci -nn | grep -i 'co-processor'`，用本表把芯片ID映射到产品型号。
> - **工具 `downgrade` 字段可能误报**：实测某 BW150×8 机型全部 `downgrade:true`，但 `lspci -vvv` 原文显示 8 卡 LnkCap=LnkSta=32GT/s Width x16（Gen5 x16 满速），**实际无降速**。链路状态判定以 `lspci -vvv` 的 LnkCap vs LnkSta 原文为准。
> - BW10 的实测芯片ID 待采集补充（推测 6370 或 6430 系列）。

### 产品型号 → 产品级 Device ID（十进制，与上方芯片级 ID 并存）

> ⚠️ **层级区分**：上方表格是 `lspci -nn` 的**芯片/板卡级设备ID**（十六进制，形如 `1d94:62b7`），
> 本表是**产品级 PCIe Device ID（十进制）**，两者层级不同、不可混用。
> - agent 解析 `lspci -nn` 时拿到的是芯片级十六进制 ID（需按上方表映射到产品型号）；
> - 本表产品级十进制 ID 用于**产品识别/资产归类**场景（如厂商工具、BMC 上报的十进制 Device ID）。
> - 例：K100 芯片级 ID 为 `1d94:62b7`（十六进制），产品级 Device ID 为 `8275`（十进制），非同一数值。

## 设备配置 BOM（来自内部测试手册《数据汇总》）

> 整机配置速查（机型 → 关键硬件）。显存已在上方型号表标注；以下补 CPU/内存/网卡/整机 DCU 配置。

### X7850H0（cascade）—— BW150（8卡）
- CPU：Hygon C86 7490 64-core Processor ×2
- 内存：DDR5 4800 32G ×24
- 存储：480G SATA SSD ×2 / 960G SATA SSD ×4
- RAID：BCM 8560-8i 4G MR ×1
- 网卡：板载双口 1G RJ45 ×1
- DCU：**BW150 ×8**
- 电源：2200W ×4

### X7850H0（cascade）—— BW100（8卡）
- CPU：Hygon C86 7490 64-core Processor ×2
- 内存：DDR5 4800 64G ×24
- 存储：480G SATA SSD ×2 / 960G SATA SSD ×4 / 7.68T ×4
- RAID：BCM 9560-8i Tri-Mode RAID ×1
- 网卡：板载双口 1G RJ45 ×1 / **MLX MCX653105A-HDAT 1-port 200G HDR QSFP56 HCA ×1**
- DCU：**BW100 ×8**
- 电源：2700W ×4

### X7950H0（OAM）—— BW1000（8卡）
- CPU：CPU 7490 2.7G 64C 400W ×2
- 内存：DDR5 5600 64G ×24
- 存储：3.84T E4x4 R SSD ×4 / 960G SATA SSD ×2
- 网卡：双口 10G OCP3.0 ×1 / **双端口 200G QSFP56 ×1** / **双端口 200G NDR HCA ×4**
- DCU：**BW1000 64GB ×8**
- 电源：2700W ×2 / 3300W 54V ×6

### X7950H0（OAM）—— BW1100（8卡）
- 同上 X7950H0 平台，DCU 换为 **BW1100 144GB ×8**（其余配置同 BW1000 机型）

> 注：BW1000/BW1100 机型配 4×200G NDR HCA，多机 rccl-test 走 200G IB（见 dcu-rccl-test 集群 mpirun 模板的 `NCCL_IB_HCA=mlx5_*`）。
