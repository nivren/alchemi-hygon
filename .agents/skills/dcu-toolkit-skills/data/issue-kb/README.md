# 问题排查知识库 (Issue Knowledge Base)

此目录存储DCU相关问题的排查记录，每个问题一个markdown文件。

## 文件命名规范

```
{问题类型}_{简要描述}.md
```

示例：
- `模型推理_OOM显存不足.md`
- `性能_绑核后性能下降.md`
- `环境_DTK版本不兼容.md`
- `通信_多卡互联报错.md`

## 问题记录模板

见 `../templates/issue-record-template.md`

## 问题记录内容

每条记录包含：
1. 问题描述（现象、报错信息）
2. 环境信息（DCU型号、DTK版本、模型、框架）
3. 排查过程（步骤、命令、中间结果）
4. 根因分析
5. 解决方案
6. 复现条件（可选）
7. 关联问题（可选）
