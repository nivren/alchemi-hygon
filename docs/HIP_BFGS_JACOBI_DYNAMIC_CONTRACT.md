# M5-3A：动态尺寸 HIP Jacobi 原型合同

2026-10-10，用户确认 M5-3A，并提供 `li_mp_data` 与 `T2_46` 作为测试数据。
这是本地新增 BFGS 的隔离求解器扩展，不是 NVIDIA 上游移植或 bugfix。
M5-2 历史合同与证据保留，产品 Registry、默认求解器和版本锁不变。

当前状态：动态原型窄验收完成，实际尺寸/Batch子集、误差、性能退化及T2独立
CPU MLIP超时边界见[M5-3A报告](../reports/g2-ase-bfgs-m5-3a.md)。原型未产品注册，
不同宽度组仍串行；[M5-3B](../reports/g2-ase-bfgs-m5-3b.md)随后已完成隔离验收；产品接入另待确认。

## 输入、输出和资源

- `raw_eigh(a, max_sweeps=100, *, chunk_size=None)` 接受非空连续 FP64 HIP
  `[n,n]` / `[B,n,n]`，n/B 为动态正整数；LOWER、无 grad、当前匹配
  Torch/DTK26.04/gfx936、forward-only eager。没有尺寸白名单或固定 B 上限。
  未支持 dtype/device/layout/UPLO 明确报错，不回退、不降精度。
- 返回独立设备张量 `(w,V,info,residual,sweeps)`；w 升序、V 的列为特征向量。
  输入不修改，UPPER 不参与矩阵定义。输出不 alias 输入，保持现有 shape。
- 索引/大小乘积使用 int64；配对局部整数必须可表示。网格按设备实际范围
  限定并以 grid-stride 覆盖全部元素/体系，不把网格上限转成逻辑 B 上限。
  显存不足与不可表示大小明确失败，不能静默忽略体系。
- `chunk_size` 是可选的隔离工作区分块参数，正整数或 None。None 一次批量；
  分块时仍在设备内执行原生 batched 核函数，并收集完整逻辑 Batch 结果。
  输出空间仍随 B*n*n 增长；分块不承诺消除所有 OOM。后续块失败时不提交状态。

## 数学和执行

- 保留 M5-2 round-robin 不相交旋转、中心化、原始矩阵范数收敛、谱恢复、
  双缓冲和逐矩阵冻结。max_sweeps 仍为整数 1..100。
- 保留 `1e-15` 残差阈值与 info=0/1/2 含义。不增加 clamp、阻尼、曲率跳过、
  线搜索、零 padding 谱或新失败回退。
- 设备内稳定排序替换固定 512 槽排序；等值按原始列顺序排序，不添加 epsilon。
  优先使用当前海光 Torch 已提供的稳定设备排序，必须实际验证 HCU 路径。
- 所有矩阵运算、排序和列重排在输入设备/current stream；主机只读取诊断标量
  和调度元数据。每 sweep 标量同步保留，不宣称全异步或无数据传输。
- 复用现有分组 BFGS 数学与全组成功后提交的规则；State、Filter、Hooks、
  模型整 Batch 求值、冻结/重排/退出/补位/配对 restart 不改变。
  本阶段不同尺寸组仍串行；多 stream 和原生异构共同调度属于待确认 M5-3B。

## 验收与性能边界

- CPU：动态奇偶尺寸配对完整覆盖、metadata/分块错误、独立 FP64 oracle。
- HCU：旧 147/285 全部回归，新增小/奇偶/199-201、511-513、552/561、1104/1113
  代表子集；实际 B8/16/32 子集、分块与一次批量一致、输入保护、非默认 stream、
  真非收敛和后块/后组失败。验收清单不写回 API 白名单。
- 保留谱 atol=2e-10/rtol=2e-11、方程/正交 <1e-10，以及既有 ASE 逐步
  Hessian/方向/坐标/maxstep 容差。不以最终收敛替代逐步数值兼容。
- 保留旧微基准三进程、两次预热、七次交替样本；新增尺寸/大 Batch/异构
  分组窗口，报告冷启动、稳态、显存和退化，不要求全部新尺寸加速。
- 真实数据从用户目录只读选择并记录文件 hash、原子数、元素、处理与种子。
  使用 MACE MPA-0 medium（不是 mace_off small）；真实独立 CIF 与复制输入
  分开计数。短步 ASE、独立运行与 Batch 对照；完整收敛/性能仅按实际完成范围报告。
- 限时单卡、运行前和期间检查竞争。未测组合、超时、数值失败明确记录。
  交付合同、源码、命令/退出码/误差/性能报告，验收后再确认 M5-3B；不自动推送。
